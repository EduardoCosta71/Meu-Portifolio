# Portfólio — Eduardo Costa Borges

Portfólio estático feito com HTML, CSS e JavaScript, inspirado na referência enviada.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.

## Personalize seus links
No `index.html`, procure por:
- `https://github.com/` e `SEU_USUARIO`
- `https://linkedin.com/` e `SEU_PERFIL`
- `seuemail@exemplo.com`
- Os links `href="#"` dos cards de projetos

Substitua pelos seus endereços reais. Você também pode editar textos, tecnologias e projetos diretamente no HTML.

## Estrutura
- `index.html`
- `css/style.css`
- `js/script.js`
